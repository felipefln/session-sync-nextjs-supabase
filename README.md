# session-sync-nextjs-supabase

Task 1: base do projeto Next.js App Router para o desafio de sessão com Supabase.

## Objetivo
- Criar a estrutura inicial do app
- Preparar a base para autenticação SSR
- Preparar o ambiente para coordenação de refresh entre abas

## Comandos
- `npm install`
- `npm run dev`

## Variáveis de ambiente
Copie `.env.local.example` para `.env.local`.
